\# ==============================

### **# Create a New React Project (Vite)**

\# ==============================



\# 1. Go to the folder where you want to create the project

cd path/to/your/folder



\# 2. Create a React project using Vite

npm create vite@latest



\# 3. Enter Project Name

\# Example:

my-react-app



\# 4. Select Framework

React



\# 5. Select Variant

JavaScript + SWC

\# (or JavaScript if SWC isn't available)

\# (Avoid TypeScript unless you're learning it)



\# 6. Move inside the project

cd my-react-app



\# 7. Install dependencies

npm install



\# 8. Start Development Server

npm run dev



\# 9. Open the link shown in terminal

\# Usually:

http://localhost:5173/





### Folder Structure You'll See

### Commands You'll Use Daily

\# Go inside project

cd project-name



\# Install packages

npm install



\# Run project

npm run dev



\# Stop server

Ctrl + C



\# Install a package

npm install package-name



\# Example

npm install axios



\# Remove a package

npm uninstall package-name
